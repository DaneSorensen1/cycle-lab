# Sorensen's Cycle Lab

Attempt-first practice for the expanded accounting cycle (Chapters 3 and 4): journal entries, posting, adjusting entries, balances and the adjusted trial balance, with hints layered underneath. Static files; no build step.

- Students: https://danesorensen1.github.io/cycle-lab/
- Teacher page: https://danesorensen1.github.io/cycle-lab/teacher.html (passcode in the file; reading the class record also needs this device's id in the `cl_teachers` collection)
- Class record: the shared Firebase project (journal-entry-arena), collections prefixed `cl_`. Publish `firestore.rules` from this repo in the Firebase console once; it contains the Cash Flow Lab and Arena rules unchanged plus the `cl_` block.

Deploy any change by pushing to `main`; Pages serves the root.
